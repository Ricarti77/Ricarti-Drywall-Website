# Ricarti Drywall — website

The new website for Ricarti Drywall: insulation, drywall and finishing for homes in the Greater Toronto Area, Hamilton, Kitchener–Cambridge and Muskoka.

- Hosted on Vercel, deployed from this repository's `main` branch.
- Languages: English, French, Italian, Portuguese, Hebrew (in that order).
- Two audiences: homeowners (`/homeowners`) and builders (`/builders`), each with its own estimate path.

Designs and the content plan live in Claude:
- Design canvas: https://claude.ai/artifact/AwM7JjdDKpUATs9pEVf3Mv
- Website plan: https://claude.ai/artifact/YExupWMk9YNocDEXBP3H4v
- Archive of the old site: https://claude.ai/artifact/4i5aYrf2NetaecxRFbUYBU

Never commit passwords, API keys or form secrets to this repository. Keep them in Vercel's environment variables.
